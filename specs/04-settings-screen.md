# Экран Настроек

Настройки разбиты на вертикальные стеки (карточки-секции).

---

## 1. Стек «Профиль» (самый крупный, первый)
- Кружок с аватаром персонажа (по центру)
- Уровень (текст, например «УРОВЕНЬ 7»)
- Количество баллов / XP
- Количество дней с начала игры («ДЕНЬ 34»)
- Кнопка «ПРОФИЛЬ» — переход в полный раздел профиля

## 2. Стек «Оформление»
- Превью 3–4 тем оформления (кружки / квадраты с образцами цветов)
- При нажатии на тему — она применяется глобально
- Название темы под каждым превью (например: «Тёмная», «Светлая», «Неон», «Лесная»)

## 3. Стек «AI / Ассистент»
- **Вариант 1:** Свой API-ключ — текстовое поле для ввода ключа + поле URL (опционально)
- **Вариант 2:** По подписке (мой API) — переключатель / радио-кнопка
- **Вариант 3:** Отключить ИИ

## 4. Другие стеки (опционально)
- **Уведомления**: вкл/выкл пуш-уведомления, время напоминаний
- **Язык**: выбор языка интерфейса (русский, английский)
- **Звуки**: вкл/выкл звуковые эффекты
- **Экспорт данных**: выгрузить историю задач в JSON/CSV
- **Сброс / Очистка**: сбросить весь прогресс (с подтверждением)
- **О приложении**: версия, автор, ссылки
