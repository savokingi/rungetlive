# Экран Персонажа (Кастомизация)

- Отдельный экран, доступен из бургер-меню (раздел «Персонаж») и с главной через кнопку «- ВЫБРАТЬ -»

## Содержимое
- Отображение текущего персонажа (крупный аватар)
- Сетка / карусель доступных скинов
- Скины открываются за достижение определённых уровней
- Заблокированные скины скрыты (не показываются)

## Интерактив
- Нажатие на открытый скин → персонаж меняется
- Пока других настроек персонажа нет (только выбор скина)
