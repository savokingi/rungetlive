# Экран дел (Задачи)

## Верхняя зона (Хедер)
- Кнопка «Назад» для возврата на предыдущий экран

## Зона календаря
- Горизонтальная скроллируемая лента квадратных плашек с датами (1–5+)
- Текущий/выбранный день выделен активным стилем
- Дата «3» отмечена как активная (пример)

## Центральная зона — список задач
- Вертикальный список карточек задач
- Каждая карточка содержит:
  - Название (например, «УБОРКА», «ОБЕД»)
  - Количество баллов (например, «+10Б», «+5Б»)
  - Временной интервал (например, «10:00–10:30», «12:00–13:00»)
  - Квадратный чекбокс для отметки выполнения
- Интерактив: свайп влево — редактирование, свайп вправо — удаление
- **Выполненная задача**: остаётся на месте, но становится менее яркой (dimmed)

## Нижняя зона (до подвала)
- Крупная овальная кнопка «ДОБАВИТЬ» — создание нового дела

## Подвал
- Нижний таб-бар для сквозной навигации (только иконки, без подписей):
  - ИИ-ассистент | Главная | Дела
