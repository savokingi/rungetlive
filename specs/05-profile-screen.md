# Экран Профиля

## 1. Шапка — Игровая карточка
- Крупный аватар (персонаж, можно нажать для смены)
- Имя / Никнейм
- Уровень + прогресс-бар XP до следующего уровня

## 2. Статистика (сетка из 4 карточек)
| 🗓 Дней в игре | ✅ Выполнено задач |
|---|---|
| ⭐ Баллов (XP) | 🔥 Уровень |

## 3. Календарь активности
- Тепловая карта (как GitHub contributions) — продуктивность по дням
- Текущий месяц, можно листать
- Цвет ячейки зависит от количества выполненных задач за день

## 4. Навигация
- Кнопка назад для возврата
