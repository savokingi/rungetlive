# Система уровней

## Механика
- Для перехода на следующий уровень нужно выполнить два условия:
  1. **Дней в игре** (с момента регистрации) — не меньше порога
  2. **XP на уровень** — заработать указанное количество баллов на текущем уровне
- При повышении уровня **XP сбрасывается до 0**, счётчик дней продолжает расти

## Заметки
- **Уровни 1–5**: первые ~3 недели, быстрый прогресс для вовлечения
- **Уровни 6–10**: 1–3.5 месяца, нужна регулярность
- **Уровни 11–19**: 4–12 месяцев, темп ~30 XP/день
- **Уровень 20**: финальный год, ~33 XP/день
