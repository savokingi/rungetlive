# Главный экран (Персонаж)

## Верхняя зона (Хедер)
- Слева: иконка бургер-меню — открывает боковую шторку с разделами:
  - Главная
  - Дела
  - ИИ-ассистент
  - Профиль
  - Персонаж
  - Достижения
  - Настройки

## Центральная зона
- Иллюстрация персонажа
- Плашка «ПЕРСОНАЖ»
- Овальная кнопка «- ВЫБРАТЬ -» → ведёт в кастомизацию (выбор скина)

## Нижняя зона (до подвала)
- Крупная скругленная кнопка-виджет → быстрый переход в раздел «Дела»

## Подвал
- Нижний таб-бар (только иконки Lucide, без подписей), 3 раздела:
  - ИИ-ассистент
  - Главная (центр)
  - Дела
