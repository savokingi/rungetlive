# Итоговая спецификация — RunGetLive

## 1. Главный экран (Персонаж)

- **Верхняя зона**: бургер-меню (слева) — боковая шторка со всеми разделами
  - Главная
  - Дела
  - ИИ-ассистент
  - Профиль
  - Персонаж
  - Достижения
  - Настройки
- **Центр**: иллюстрация персонажа, плашка «ПЕРСОНАЖ», кнопка «- ВЫБРАТЬ -» → ведёт в кастомизацию (выбор скина)
- **Нижняя зона**: крупная скругленная кнопка-виджет → быстрый переход в раздел **Дела**
- **Подвал**: таб-бар (только иконки Lucide, без подписей), 3 раздела:
  - ИИ-ассистент
  - **Главная** (центр)
  - Дела

## 2. Экран дел (Задачи)

- **Хедер**: кнопка «Назад»
- **Календарь**: горизонтальная скроллируемая лента дней (прямоугольные плашки, активный день выделен)
- **Список задач**:
  - Название, баллы (+10Б), время (10:00–10:30), чекбокс
  - Свайп влево → редактирование, свайп вправо → удаление
  - **Выполненная задача**: остаётся на месте, но становится менее яркой (dimmed)
- **Кнопка «ДОБАВИТЬ»** → открывает модалку
- **Пустое состояние**: «Задач пока нет»

### Модалка добавления / редактирования задачи
- Название (текст)
- Баллы (число)
- Время (time range)
- Дата (date)
- Повторение: пользователь выбирает дни недели и дату окончания
- Одна и та же модалка для добавления и для редактирования

## 3. ИИ-ассистент
- Диалоговый интерфейс: сообщение пользователя (право) → ответ ИИ (лево)
- ИИ распознаёт задачи из текста, показывает виджет с предпросмотром
- У каждой распознанной задачи: карандаш (редактировать) и чекбокс (добавить в список)
- **AI-интеграция**:
  - По подписке — мой API (Gemini)
  - Свой API-ключ (пользователь вводит сам)
  - Отключён

## 4. Настройки
Стек-секции:
- **Профиль** — аватар, уровень, баллы, дни в игре, кнопка «ПРОФИЛЬ»
- **Оформление** — выбор темы (светлая / тёмная + акцентный цвет из палитры)
- **AI** — 3 варианта: свой API, подписка, отключено
- **Уведомления** — вкл/выкл, время напоминаний
- **Язык** — русский, английский
- **Звуки** — вкл/выкл
- **Экспорт данных** — JSON/CSV
- **Сброс прогресса** — с подтверждением
- **О приложении**

## 5. Профиль
- Аватар (персонаж), имя/ник, уровень + XP-бар
- Сетка статистики: дни в игре, выполнено задач, баллов, уровень
- Календарь активности (тепловая карта, как GitHub contributions)

## 6. Достижения
- Отдельный экран (детали позже)

## 7. Персонаж / Кастомизация
- Отдельный экран (доступен из бургер-меню и с главной через «ВЫБРАТЬ»)
- Скины, которые выдаются за уровни
- Пользователь видит только открытых персонажей (заблокированные скрыты)
- Пока доступна только смена скина, других настроек персонажа нет

## 8. Уровни и XP
- Для перехода на следующий уровень нужно:
  - **Дней в игре** — не меньше порога (растёт с даты регистрации)
  - **XP на уровень** — заработать указанное количество на текущем уровне
- При повышении уровня **XP сбрасывается до 0**, дни продолжают копиться
- Полная таблица: см. `07-levels.md`

## 9. Навигация
- **Бургер-меню** → все разделы (Главная, Дела, ИИ-ассистент, Профиль, Персонаж, Достижения, Настройки)
- **Таб-бар** → 3 раздела: ИИ-ассистент | Главная | Дела
- **Горячая кнопка на главной** → Дела
- **Кнопки внутри разделов** → переходы

## 10. Стили
- Шрифт: системный Apple (San Francisco)
- Скругление: единое, кнопки pill-style (Apple), аватар круглый
- Карточки: плоские, с обводкой акцентным цветом, без теней, без градиентов
- Иконки: Lucide (таб-бар — только иконки, без подписей)
- Ховер не нужен (mobile-first)

## 11. Прототип
- Онбординг (первый запуск / создание персонажа) — **не нужен**
- Приложение открывается сразу в прототипном режиме
