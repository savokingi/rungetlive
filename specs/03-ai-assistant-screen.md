# Экран ИИ-ассистента

## Верхняя зона (Хедер)
- Кнопка «Назад» для возврата в предыдущий раздел

## Центральная зона — диалог с ИИ
- Сообщение пользователя (выровнено по правому краю):
  - Текст: «МНЕ НУЖНО ЗАВТРА СХОДИТЬ НА ЗАНЯТИЕ И ПРИБРАТЬСЯ»
- Ответ ИИ (выровнен по левому краю):
  - Текст: «ОТЛИЧНО, ВНЕСУ В СПИСОК ДЕЛ.»
  - Интерактивный скругленный виджет со списком распознанных задач:
    - «УБОРКА +10Б» + иконка карандаша (редактировать задачу)
    - «ЗАНЯТИЕ 14:00-15:30 +20Б» + чекбокс (подтвердить и добавить в список)

## Нижняя зона — ввод сообщения
- Поле ввода со скругленными углами
- Плейсхолдер: «НАПИШИ...»
- Справа круглая кнопка отправки с иконкой стрелки

## Подвал
- Нижний таб-бар для сквозной навигации

## Примечания
- ИИ распознаёт задачи, время и баллы из текста
- Пользователь может отредактировать задачу перед добавлением или подтвердить чекбоксом
- После подтверждения задача попадает в список дел на выбранный день
